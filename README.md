#### 📌 Featured work

| Project | What it is |
|---|---|
| [**mas-decision-provenance**](https://github.com/oussemaAbdaoui/mas-decision-provenance) | Records every run of a 3-agent LLM chain as a PROV-style provenance graph. Finds which inputs really determined the decision (graph-restricted perturbation and partial replay, tested against the run-to-run noise floor) and checks them against the agent's own justification. Fully reproducible offline. |
| [**paperlens**](https://github.com/oussemaAbdaoui/paperlens) | Research assistant that answers questions over a personal paper corpus with grounded, page-level citations. RAG with BGE-M3, FAISS, BGE-Reranker and GPT-4o. |
| [**cognitive-navigation**](https://github.com/oussemaAbdaoui/cognitive-navigation) | Robot navigation that combines spatial reasoning with LLM-based planning. |
| [**parcours**](https://github.com/oussemaAbdaoui/parcours) | Planner for job, master's and PhD searches with live listings from many sources, CI and tests. |
